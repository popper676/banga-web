# BANG GA BANG GA

High-fidelity Next.js UI prototype for the BANG GA BANG GA restaurant platform.

## Included interfaces

- Responsive customer ordering website
- Restaurant admin panel
- iOS application frames
- Android application frames
- Ordering, payment, delivery, inventory and customer-management flows

## Technology

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Validation

```bash
npm run typecheck
npm run build
```

This repository currently contains a front-end prototype with mock data. Production payment, delivery, authentication and database integrations require backend credentials and environment configuration.
